# holan.eu

## Cíl
Jednoduchý, moderní osobní web prezentující služby (Web Analytics, Automatizace & AI, Tvorba webů). Obsah cílí na malé firmy a živnostníky.

## Tech
- Čisté HTML / CSS / JS, žádný framework
- Responsivní design
- Hosting: GitHub Pages → [holaneu/web-holan-eu](https://github.com/holaneu/web-holan-eu)

## Git deployment
Deployment je automatizovaný přes GitHub Actions:
- push do `main` → nasazení na GitHub Pages (produkce)
- push do `dev` → nasazení na Netlify / Cloudflare Pages (staging preview) — *zatím neřešeno*
